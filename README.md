# Código de Dios — Versión 2

Aplicación PWA tipo libro y glosario bíblico.

## Contenido
- 12 capítulos temáticos.
- 300 fichas de estudio por capítulo (3,600 fichas en total).
- Nuevos capítulos 3 y 4: **Promesas de Dios** y **Cómo orar a Dios**.
- Cada ficha incluye referencia, subtema, interpretación específica para el capítulo y aplicación práctica.
- Texto bíblico RV1909 cargado cuando hay conexión.
- Buscador, favoritos, progreso, notas, lectura en voz alta, impresión, modo oscuro e instalación PWA.

Sube todos estos archivos a la raíz del repositorio de GitHub Pages.
